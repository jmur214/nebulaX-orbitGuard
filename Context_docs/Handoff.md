# NebulaX AI Handoff: Astra Dynamics Wargame Platform
**Date:** December 5, 2025
**Status:** Visual Prototype (Hybrid Mode)
**URL:** [Dashboard](http://localhost:3000) | [Core](http://localhost:8000)

## 🧠 User Sentiment & Philosophy
*   **"Visuals First"**: The user prioritizes the "Look and Feel". The system must *look* like a high-stakes cyber war room. Aesthetics, animations, and "cool factor" are critical.
*   **"Realistic Simulation"**: Even if the data is synthetic, the experience should feel authentic. We use terms like "Red Team" (not Cell), simulate secure login terminals, and display detailed telemetry.
*   **"Gamification"**: The "Tug of War" score bar and DEFCON levels are central to the narrative. The user enjoys seeing the system react to events.

## 🏗️ System Architecture (Hybrid)
Due to disk space constraints, we run a **Hybrid Environment**:
1.  **Docker**: Runs `Postgres` and `Redis` only.
2.  **Native**: Runs `FastAPI` (Core) and `Next.js` (Dashboard) on the host.
3.  **Controller**: `wargame_controller.py` orchestrates the Python agents.

### Key Components
*   **Core API (`services/core`)**: FastAPI app. Handles event ingestion, Game State calculation (Score/DEFCON), and Team Filtering.
*   **Dashboard (`services/dashboard`)**: Next.js app.
    *   **Login**: Simulated RBAC (`/login`).
    *   **Personas**: Red Team, Blue Team, Space Command, Fusion Center.
    *   **Shared**: `WarHeader` (Score Bar), `EventLog`, `SatelliteMap`.
*   **Agents**:
    *   `red-team/attack-engine`: Generates attacks (SQLi, SSH Brute Force).
    *   `blue-team/detection-engine`: Detects attacks and triggers alerts.
    *   `space-guard/tracker`: Calculates satellite TLE/Orbits.

## 🚀 Future Roadmap (Where to go from here?)
The user is interested in evolving this from a "Viewer" to a "Playable Game".

### 1. Interactive Wargame (Priority)
*   **Goal**: Make the dashboard controls functional.
*   **Features**:
    *   **Blue**: Buttons to "Block IP" or "Deploy Patch" that actually stop the Red Agent.
    *   **Red**: "Launchpad" to trigger specific attacks on demand.
    *   **Space**: Controls to "Re-orient Satellite".

### 2. AI-Driven Narrative
*   **Goal**: Replace random scripts with LLM personalities.
*   **Features**:
    *   Syndicate and SecOps agents generating realistic chat logs/emails.
    *   Dynamic attack payloads generated by LLMs.

### 3. Real Infrastructure
*   **Goal**: Move from simulation to real tools.
*   **Features**:
    *   Red Agent running actual `nmap`/`hydra`.
    *   Blue Agent running actual `Suricata`/`Wazuh`.
    *   Deploying a vulnerable target container (e.g., DVWA).

## 🛠️ How to Resume Work
1.  **Start DB**: `docker compose up -d postgres redis`
2.  **Start Dashboard**: `cd services/dashboard && npm run dev`
3.  **Start Simulation**: `python3 wargame_controller.py`
4.  **Check Status**: `curl http://localhost:8000/game/state`
