description: Plan a New Feature (Director Level)
---
1. **Strategic Alignment:**
   - Check `NebulaX_Master_Plan.md`: Does this feature align with an "End State" vision?
   - Check `Reminders.md`: Does it violate any protocols (e.g., 3D Globes)?
2. **Resume Value:**
   - Ask: "What bullet point will this add to `NebulaX_Resume_Assets.md`?"
   - If the answer is "None", reconsider the feature or refactor it to be more "Enterprise-Grade".
3. **Architecture Check:**
   - Check `NebulaX_System_Context.md`: Where does this fit in the topology?
   - Define the `UniversalEvent` schema for any new data streams.
4. **Output:**
   - Create a `implementation_plan.md` detailing the above.
